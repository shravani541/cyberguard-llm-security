## 🚀 Quick Start

### Option 1: Google Colab (Recommended — Free T4 GPU)

1. Open [`notebooks/cyberguard_training.ipynb`](notebooks/cyberguard_training.ipynb) in Colab
2. Set Runtime → T4 GPU
3. Add your `HF_TOKEN` in Colab Secrets
4. Run all cells (≈ 15-25 min on T4)

### Option 2: Local Training

```bash
# 1. Install dependencies
pip install unsloth trl peft transformers datasets mlflow

# 2. Build dataset
python data/build_dataset.py

# 3. Start MLflow tracking server
mlflow server --port 5000 &

# 4. Train
python training/train.py --config training/config.yaml

# 5. Evaluate
python evaluation/evaluate.py \
  --base_model unsloth/Llama-3.2-3B-Instruct \
  --finetuned_model ./outputs/merged_model

# 6. View results
open results/comparison_table.md
```

### Option 3: Run the Inference API

```bash
# Export your model path
export MODEL_PATH=./outputs/merged_model

# Start full stack (API + MLflow UI)
cd serving
docker compose up -d

# Test the API
curl -X POST http://localhost:8000/analyze \
  -H "Content-Type: application/json" \
  -d '{
    "code": "def login(u,p):\n  q=f\"SELECT * FROM users WHERE user=\'{u}\' AND pwd=\'{p}\'\"\n  return db.execute(q).fetchone()",
    "language": "Python"
  }'
```

## 🧠 Model Architecture

```
Base: Llama-3.2-3B-Instruct (3 billion parameters)
      ↓
4-bit NF4 Quantization (via bitsandbytes)
      ↓
LoRA Adapters (rank=16, alpha=32)
  Target: q_proj, k_proj, v_proj, o_proj
          gate_proj, up_proj, down_proj
      ↓
Fine-Tuned on Security Dataset
  - OWASP Top 10 vulnerability examples
  - Python + JavaScript code
  - CWE-annotated analysis
      ↓
CyberGuard Security Analyst
```

**Training Stats:**
- Trainable params: ~24M / 3B (0.8%) — true PEFT
- GPU VRAM needed: ~6GB (T4 compatible)
- Training time: ~15-25 min on T4

## 🔧 Hyperparameter Guide

Edit [`training/config.yaml`](training/config.yaml):

| Param | Default | When to Change |
|-------|---------|---------------|
| `lora.r` | 16 | Increase to 32/64 for better quality (more VRAM) |
| `lora.lora_alpha` | 32 | Keep at 2x rank |
| `training.learning_rate` | 2e-4 | Lower to 1e-4 if training is unstable |
| `training.num_train_epochs` | 3 | Increase to 5 for more data |
| `training.per_device_train_batch_size` | 2 | Lower to 1 if OOM |

## 🧪 Adding More Training Data

Edit `data/build_dataset.py` and add to `CURATED_EXAMPLES`:

```python
CURATED_EXAMPLES.append(SecuritySample(
    vulnerable_code="...",
    language="Python",
    vuln_type="SSRF",
    cwe_id="CWE-918",
    owasp_category="A10:2021 - SSRF",
    vulnerable_line="...",
    impact="...",
    secure_code="...",
    explanation="...",
    severity="HIGH",
    references=["https://owasp.org/Top10/A10_2021-Server-Side_Request_Forgery_%28SSRF%29/"]
))
```

Currently implemented CWEs: `CWE-89, CWE-78, CWE-79, CWE-22, CWE-502, CWE-798, CWE-639`
